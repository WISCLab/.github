# WISCLab @ UW–Madison
**Wisconsin Intelligibility, Speech, and Communication Laboratory**
🔗 [kidspeech.wisc.edu](https://kidspeech.wisc.edu/)

WISCLab researches children's speech intelligibility and communication development. This organization hosts the open-source tools and data utilities that support that work.

## For Visitors & External Contributors

We welcome contributions to our public repositories. To get started:

1. **Read the repo-level README** for any project you plan to work on.
2. **Install [shred-guard](https://github.com/WISCLab/shred-guard)** to verify that no common PHI patterns are present in code intended for GitHub. All contributions that touch data pipelines should have shred-guard configured.
3. Follow existing code style and conventions within each repository. When in doubt, open an issue or ask.

Please open an issue before submitting large changes so we can discuss the approach.

## For Lab Members

New lab members should be added to this GitHub organization to access private repositories and internal tools. If you haven't been added yet, reach out to [@tjmahr](https://github.com/tjmahr).
